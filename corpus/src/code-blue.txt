Code Blue Procedure

1. Recognition
A patient who is unresponsive and not breathing normally needs a Code Blue.

2. Activation
Dial extension 5555 and state "Code Blue" with the unit and room number. Start chest compressions immediately.

3. Equipment
Bring the crash cart and attach the defibrillator pads as soon as it arrives.
